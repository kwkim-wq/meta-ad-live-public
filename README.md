# meta-ad-live — 설치 안내 (담당자용)

소재 파일(영상·이미지)을 주면 **Claude Code가 메타 광고를 캠페인부터 라이브까지 만들어주는** 도구입니다.

---

## ⛔ 먼저 읽을 것

| | |
|---|---|
| **돈이 나가는 시점** | 광고 생성까지는 전부 PAUSED(꺼진 상태) = 과금 없음. **라이브(ACTIVE)로 켜는 순간부터 과금**됩니다. |
| **켜기·삭제는 3번 확인** | "켜줘"·"삭제해줘"라고 해도 Claude가 **3단계로 나눠 확인**한 뒤에 실행합니다.<br>① 대상 확인(계정·캠페인·광고 수·예산) → ② 되돌릴 수 없는 결과 확인(과금 시작 / 복구 불가) → ③ 실행 직전 최종 확인.<br>급할 때 "3번 묻지 말고 그냥 해"라고 하면 1회 확인으로 줄입니다.<br>**끄기·예산 낮추기는 확인 없이 즉시 실행**합니다(손해를 막는 방향이라서). |
| **일예산 기본값** | **100,000원**. 다르면 요청할 때 같이 말해주세요. |
| **토큰 관리** | 토큰은 광고 계정을 열 수 있는 열쇠입니다. 외부(개인 메일·오픈 채팅 등)로 내보내지 마세요. **광고비가 오집행될 수 있습니다.** |
| **앱 시크릿** | ⛔ Meta 앱 설정에서 **App Secret 재설정 금지.** 누르면 기존에 발급된 토큰이 전부 무효화되어 연결된 자동화가 멈춥니다. |

---

## 설치 (1분)

### 사전 준비
- **Claude Code** 설치돼 있어야 합니다.
- **Python 3** 설치돼 있어야 합니다. (없으면 setup이 알려줍니다 → https://www.python.org/downloads/ , Windows는 설치 화면에서 **`Add python.exe to PATH` 체크 필수**)
- **토큰은 없어도 됩니다.** 설치 후 Claude가 발급을 도와줍니다.

### Windows
1. 받은 zip을 압축 풀기
2. 폴더 안 **`setup.ps1`** 우클릭 → **PowerShell에서 실행**
   - 실행이 막히면 터미널에서: `powershell -ExecutionPolicy Bypass -File setup.ps1`
3. `토큰>` 이 나오면 토큰이 있으면 붙여넣고 Enter, **없으면 그냥 Enter**

### macOS
1. 받은 zip을 압축 풀기
2. 터미널에서 그 폴더로 이동한 뒤: `bash setup.sh`
3. `토큰>` 이 나오면 토큰이 있으면 붙여넣고 Enter, **없으면 그냥 Enter**

### 마지막 단계 (필수)
1. **Claude Code를 완전히 닫고 다시 엽니다.** 안 하면 스킬이 인식되지 않습니다.
2. Claude에게 **"SETUP.md 보고 세팅해줘"**라고 말합니다. 광고계정·페이지 설정을 처음부터 알아서 안내해줍니다.

## 사용법

Claude Code에서 소재 폴더 경로와 함께 이렇게 말하면 됩니다.

```
이 폴더 소재로 광고 만들어줘
C:\Users\...\소재\여름특가\
```

Claude가 필요한 걸 물어보고(제품·소재설명·일예산·타겟), 문구를 안 주면 성과 데이터를 보고 3~5개 제안합니다.
확정하면 업로드 → 캠페인 → 광고세트 → 소재 → 광고 → 미리보기까지 만들고, **켜기 전에 확인을 받습니다.**

말할 때 같이 주면 좋은 것:
- 제품명 — 목록은 `reference/products.json`
- 소재 설명 (캠페인명에 들어감. 예: 여름특가, 쇼호스트)
- 일예산 (기본 100,000원)
- 타겟 (기본 18~65 남녀)

## 안 될 때

| 증상 | 조치 |
|---|---|
| `Python 3 이 없습니다` | Python 설치 후 **터미널 새로 열고** setup 다시 실행 |
| `config.json 이 없습니다` | Claude에게 "SETUP.md 보고 세팅해줘"라고 하세요 |
| MCP 서버 X로 나옴 | 정상입니다. 미리보기 기능만 못 쓰고 광고 제작은 다 됩니다 |
| `토큰이 사용 불가 상태` / `401` | 토큰 만료 또는 잘못 복사. Claude에게 "SETUP.md 보고 세팅해줘"라고 하면 재발급을 도와줍니다 |
| Claude가 스킬을 못 찾음 | Claude Code를 **완전히 종료**하고 재실행했는지 확인 |
| 그 외 | setup 화면의 메시지를 그대로 캡처해서 Claude에게 물어보세요 |

토큰을 바꾸려면 setup을 다시 실행하면 됩니다(덮어쓰기).

## 구성 파일

- `SETUP.md` — 세팅 안내 (Claude가 읽음)
- `setup.sh` — macOS 설치
- `scripts/config.py` — 설정 로더
- `scripts/setup_wizard.py` — 계정·페이지 자동 조회 및 config 생성
- `config.json` — 세팅 시 생성되는 회사별 설정

상세 절차·함정은 `SKILL.md`를 참고하세요.
